# Security and privacy

BugDrop is an early debugging utility, not a security boundary or a forensic recorder. Page-provided evidence can be forged. Pattern masking cannot identify all secrets or personal information. Screenshots require human review.

If you discover accidental sensitive-data collection or unauthorized capture, use a synthetic reproduction. Do not place actual private data in public issues. Until a private reporting channel is configured, contact the repository owner through a mutually available private channel before disclosing sensitive details.

Stop the recording and delete the report from the review page to remove retained extension data. Uninstalling removes extension storage; downloaded reports, screenshots, and clipboard copies must be deleted separately.
